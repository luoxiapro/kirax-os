# Glass 设计规范 — Space OS 视觉系统版本 1.0

> 适用范围：Space OS 桌面环境所有窗口、面板、控件、通知、开始菜单、任务栏。
> 设计目标：在 BCM2709（Cortex-A7 @ 900MHz，无 GPU 模糊）上实现 iOS 26 / visionOS 风格的液态玻璃质感，
> 通过低分辨率预计算模糊 + 脏矩形缓存 + 性能降级开关达成可用帧率。

---

## 1. 深空底色（Wallpaper Layer）

| 参数 | 值 | 说明 |
|---|---|---|
| 渐变起点（顶） | `#070914` (RGB 7,9,20) | 近黑蓝 |
| 渐变中点（屏高 55%） | `#10142E` (RGB 16,20,46) | 蓝紫 |
| 渐变终点（底） | `#1C1636` (RGB 28,22,54) | 星云紫 |
| 星点数量 | 全屏 240 颗（性能档 80） | 颜色 `#F0F4FF`，每颗 alpha 60–219，尺寸 1–2px |
| 装饰矢量 | 1 个行星（右下，行星橙 `#FF9F45` + 1 条轨道环 `#4FD8EB`）+ 1 枚火箭（左上，星云紫 `#8B7CF6`） | 几何矢量，禁 emoji |
| 壁纸模糊预计算 | 壁纸先 1/2 降采样（如 1920×1080 → 960×540） | 模糊在降采样层做，再放大回去 |

> 上述令牌权威来源为 `crates/space-core/src/glass.rs`（`palette` / `GLASS`），桌面落地见 `kernel/src/desktop/mod.rs`。

壁纸层是唯一被模糊的层。所有玻璃面板只引用壁纸的降采样模糊缓存，**不实时模糊壁纸全分辨率**。

## 2. 玻璃面板参数表（三档性能，对应 `GlassMode`）

| 参数 | 性能档 `Performance` | 轻玻璃 `Lite` | 完整 `Full`（默认） |
|---|---|---|---|
| 背景模糊半径 sigma | 0（关模糊） | 4 px | 8 px（均在 1/2 降采样层上） |
| 三次盒式模糊 pass | 0 | 3 | 3 |
| 模糊降采样倍率 | — | 1/2 | 1/2 |
| 面板底色 | 纯色 `#1C2038` alpha=235（`panel_fill_solid`） | 半透明白 `#FFFFFF` alpha=26 叠在模糊壁纸上（`panel_fill`） | 同 Lite（alpha=26） |
| 深色面板（任务栏/开始菜单） | `#101228` alpha=150（`panel_dark`） | 同左 | 同左 |
| 圆角半径（跨档固定） | 窗口 22 / 面板 14 / 按钮 9 / 通知 16 px | 同左 | 同左 |
| 边缘高光描边 | 上 1px `#FFFFFF` alpha=64、左 alpha=36；下 1px `#000000` alpha=90、右 alpha=60；内部上缘发光 alpha=38 | 同左 | 同左；悬停外发光 `#78A0FF` alpha=60 |
| 噪声纹理 | 去噪 | strength=6 / tile=64 | strength=6 / tile=64 |
| 同屏玻璃面板上限 | 0（退回纯色面板，圆角/描边保留） | 2 | 4 |
| 模糊面积占屏比上限 | — | 20%（超过则自动降级） | 20% |
| 脏矩形缓存 | 每面板独立 | 每面板独立 + 壁纸模糊区缓存 | 全局合成缓存 |

> 切换入口：设置 → 外观 → "液态玻璃效果" 开关（切到 `Performance`）。
> 自动降级：模糊面积占屏比 > 20% 时从 `Full`→`Lite`→`Performance` 逐档降级（`max_blur_area_ratio=20`）。

## 3. 字体与文字

| 元素 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 大标题 / 显示 | 28 px（`size_display`） | 常规 | `#EEF1FF` alpha=240（TEXT_PRIMARY） |
| 窗口标题 / 任务栏时间 | 20 px（`size_title`） | 常规 | `#EEF1FF` alpha=240（TEXT_PRIMARY） |
| 正文 / 按钮文字 | 16 px（`size_body`） | 常规 | `#EEF1FF` alpha=240（TEXT_PRIMARY） |
| 次要文字 | 12 px（`size_small`） | 常规 | `#BEC4E0` alpha=200（TEXT_SECONDARY） |
| 禁用文字 | 12 px | 常规 | `#8C94B4` alpha=160（TEXT_DISABLED） |

字体：当前为 8×8 位图字体（`kernel/src/font.rs` 的 `FONT8X8`），按整数倍缩放渲染；行高 22px。禁 emoji，所有图标用几何矢量路径（行星、轨道环、火箭、圆点）。

## 4. 组件规格

### 4.1 窗口
- 外圆角：22 px（`corner_window`）
- 标题栏高度：24 px（顶部 24px 即拖拽命中区），背景为内部上缘发光 `inner_glow` rgba(255,255,255,38)，标题文字 `TEXT_PRIMARY`
- 关闭/最小化圆点按钮：当前未绘制（规划项）
- 窗口阴影：向右下偏移（x+4, y+6），`drop_shadow` rgba(0,0,0,120)，不做高斯模糊（性能考虑）

### 4.2 任务栏（底部悬浮液态玻璃条）
- 高度：40 px
- 圆角：14 px（`corner_panel`）
- 距边距：左右各 24 px，底 16 px（`Rect(24, h-56, w-48, 40)`）
- 背景：玻璃面板从壁纸模糊缓存取样；性能档退回 `panel_dark` rgba(16,18,40,150)
- 内容：左侧火箭图标（半径 12，`ORBIT_CYAN`），右侧文本时钟 `HH:MM:SS`；性能档前缀 `[PERF]`（`PLANET_ORANGE`）

### 4.3 开始菜单（磨砂玻璃弹出层，F1 切换）
- 尺寸：260×296 px（`Rect(24, h-56-300, 260, 296)`）
- 圆角：14 px（`corner_panel`）
- 玻璃参数：完整档从壁纸模糊缓存取样（模糊半径 8px，1/2 降采样）
- 列表：About / Calculator / Clock / Terminal 共 4 项，行距 40 px，每项前置 3 px 圆点（`ORBIT_CYAN`）

### 4.4 通知卡片
- 尺寸：320×64 px
- 圆角：16 px（`corner_notification`）
- 位置：右上角堆叠，最多 3 条，卡片行距 72 px
- 停留：演示 ttl = 5 秒（约 300 帧 @60fps）
- 玻璃参数：性能纯色面板 `panel_fill_solid`；上缘 1px 高光

## 6. 渲染管线（CPU only）

1. 绘制壁纸层（渐变 + 星点 + 行星矢量）到 backbuffer。
2. 壁纸降采样 1/2（`blur_downsample=2`）→ 对降采样层做三次盒式模糊（sigma 按档位：Full 8 / Lite 4 / Performance 0）。
3. 把模糊后的降采样层放大回原尺寸，作为 glass_blur_cache。
4. 按 z-order 合成：壁纸 → 各玻璃面板（从 glass_blur_cache 取面板区域像素，叠加面板底色 alpha 混合）→ 边框高光 → 文字 → 指针发光。
5. 脏矩形：只重绘发生变化的窗口区域；壁纸模糊缓存只在壁纸变化时重算。

> 性能预算（目标）：1920×1080 下，平衡模式桌面 + 6 面板 ≥ 30fps。
> 单次合成预算 ≤ 33ms。壁纸模糊预计算 ≤ 16ms（启动时一次）。
