# 阶段四：图形子系统与 Glass 桌面

## 渲染原语（crates/kirax-core）

| 模块 | 功能 |
|---|---|
| `blend.rs` | alpha 混合（`blend_pixel`/`blend_pixel_alpha`，操作 `&mut [u8]`） |
| `blur.rs` | 三次盒式模糊近似高斯，`box_width_for_sigma` + `gaussian_blur_3box` |
| `roundrect.rs` | 圆角矩形覆盖率采样 |
| `fmath.rs` | 无 libm 的 sqrt/floor/round/pow（thumbv7a-none-eabi 无 f32 内建） |

## 玻璃效果优化策略

1. **只模糊壁纸层**：面板背景不是实时模糊全屏，而是从壁纸的 1/2 降采样模糊缓存取区域。
2. **降采样模糊**：壁纸先缩到 1/2，在小图上做三次盒式模糊，再放大回去。模糊半径参数见 `specs/GLASS_DESIGN.md`。
3. **脏矩形**：只重绘变化窗口的矩形区域；壁纸模糊缓存只在壁纸切换时重算。
4. **性能降级开关**：
   - 设置中"液态玻璃"开关 → 关 → 所有面板退回纯色（性能档）。
   - 自动降级：fps < 20 持续 3s → 逐档降（极致→平衡→性能）。

## 窗口系统

- 窗口树：z-order、标题栏、内容区。
- 合成：按 z-order 把壁纸 → 玻璃面板（从模糊缓存取背景 + alpha 叠加）→ 边框高光 → 文字 → 指针发光依次画。
- 事件分发：鼠标移动/按下 → 命中测试 → 顶层窗口拖拽/点击；键盘 → 焦点窗口。

## 桌面组件

- 底部悬浮液态玻璃任务栏（圆角胶囊）。
- 磨砂玻璃开始菜单（4×N 图标网格）。
- 窗口拖拽、通知卡片滑入。
- 全部遵循 `specs/GLASS_DESIGN.md`，禁 emoji，图标为几何矢量。

## 常见坑

| 症状 | 原因 |
|---|---|
| 模糊闪烁 | 每次重绘都全图模糊，没用脏矩形 |
| 玻璃面板太卡 | 没降采样，直接在全分辨率做模糊 |
| 混合写错 | 临时数组 `dst[..4].try_into()` 拿到的是副本不是原像素 |
