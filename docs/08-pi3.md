# 阶段八：树莓派 3 Model B 适配

Pi3（BCM2837，四核 Cortex-A53）在 AArch32 模式下外设基址与 Pi2 相同
（0x3F000000），中断/定时器/EMMC/USB/framebuffer 驱动全部复用；
唯一差异是 GPIO14/15 默认走 **PL011 UART0**（而非 mini UART）。

## 实施
- `kernel/src/pl011.rs`：全新 PL011 驱动（GPIO14/15→ALT0+上拉、19.2MHz 分频、
  波特率 115200；init 首步自配 cprman UART 时钟）
- `kernel/src/console.rs`：`#[cfg(feature="pi3")]` 转发 PL011 为全局 CONSOLE
- `kernel/Cargo.toml`：新增 `pi3` feature
- `Makefile`：`pi3` / `pi3-qemu` / `pi3-gdb` / `pi3-install` 目标（cortex-a53 编译、
  真机 0x8000 链接脚本 + QEMU 0x10000 独立链接脚本；`pi3-gdb` 配套
  `qemu/gdb_script_pi3.gdb`，symbol-file → `build/pi3/qemu-kernel.elf`）
- AArch64（64 位）分支另见顶层 `pi3-aarch64` 目标（产物 `build/pi3-aarch64/kernel8.img`，
  启动代码内嵌于 `kernel/src/start64.rs`，本文不展开）。

## 验证
`make pi3-qemu` → `qemu-system-arm -M raspi2b -kernel build/pi3/qemu-kernel.elf
-display none -serial stdio -serial null`（外设模型与 raspi3b 一致；banner 显示
BCM2837 AArch32，板载自检 14/14 PASS）。

## 三大坑（均已修复）
1. **QEMU cprman 时钟未使能**：raspi 模拟复位后 uart mux 时钟为 0，PL011 卡 TXFF；
   驱动 init 自配 CM_UARTCTL（源=osc 19.2MHz，DIVI=1）。
2. **QEMU BUSY 恒 1**：模拟器将 cprman BUSY 位在使能后恒置 1，不能等待清除，
   改为短延时（真机同样适用）。
3. **feature 缓存**：改 Cargo feature 后旧 .a 缓存会链接旧代码，需 `cargo clean`
   或 `touch` 触发重编（Makefile 已内置 clean 提示）。

## 烧录
`make pi3-install`（dd bs=512 seek=1 写入 kernel7.img），SD 卡第一分区 FAT32
保留官方 bootloader 文件。
