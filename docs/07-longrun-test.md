# 7×24 小时长稳测试计划

## 目标
验证 Space OS 内核在树莓派 2 真机上连续运行 7 天无内存泄漏、无死锁、无温度告警。

## 监控项

| 指标 | 采集方式 | 阈值 |
|---|---|---|
| 内存泄漏 | 每小时 klog! 输出 buddy free_bytes | 1 天内空闲堆下降 < 5% |
| CPU 负载 | idle 进程占比 | idle > 50%（空闲时） |
| 温度 | GPIO 读 BCM2709 温度传感器 | < 75°C |
|  panic 计数 | 串口统计 "KERNEL PANIC" | 0 |
| 帧缓冲 | 每小时截图首像素校验 | 非全黑 |

## 步骤

1. 烧录 `build/kernel7.img` 到 SD 卡，接串口 + 网线。
2. 启动后自动跑负载：打开 5 个 .kir 应用循环切换，每 10 秒拖动窗口。
3. 串口日志通过 `screen /dev/ttyUSB0 115200` 记录到文件。
4. 每 24 小时分析日志：grep "free_bytes" 序列，画内存曲线。
5. 7 天后汇总：泄漏量、panic 次数、峰值温度、帧缓冲完整性。

## 通过标准

- 0 次 KERNEL PANIC
- 7 天空闲堆下降 < 10%
- 峰值温度 < 80°C
- 无死锁（串口持续有 heartbeat 输出）
